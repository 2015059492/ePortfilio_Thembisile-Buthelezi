# Thembisile Buthelezi — M.Ed. ePortfolio

Monochrome multi-page website, ready for GitHub Pages.

## Upload
Upload **the contents of this folder** to the root of a public GitHub repository. Under Settings → Pages, deploy from `main` and `/ (root)`.

## Site navigation
- `index.html`: concise landing page
- `about.html`: professional introduction and research interests
- `performances.html`: six project links
- `performance-1.html` through `performance-6.html`: individual case studies
- `practice.html`: selected professional experience
- `background.html`: education and community work
- `contact.html`: contact information
