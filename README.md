# Thembisile Buthelezi — EDTC capstone ePortfolio

Monochrome, mobile-responsive HTML portfolio for GitHub Pages. Six accordion case studies, a professional profile and real supporting artifacts are included.

## Publish on GitHub Pages

1. Create a GitHub repository (e.g. `edtc-eportfolio`).
2. Upload `index.html`, `assets/`, and `artifacts/` to its root.
3. Open Settings → Pages → Deploy from branch → main → /(root) → Save.
4. When published, test all artifact downloads, site links, and mobile navigation.
